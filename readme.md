# Project list

## YouTube extension

A YouTube extension that was originally created for exporting subtitles to a text file,
but over time its functionality has changed somewhat.
Now it is an extension with several features that I use from time to time.

- [addons.mozilla.org](https://addons.mozilla.org/ru/firefox/addon/youtube-transcript-to-text/)
- [Chrome Web Store](https://chromewebstore.google.com/detail/save-youtube-transcript-a/cmahblfkoacaigpfdefeoapecbccogoo)
- [Source code](https://github.com/andrew2020wit/youtube-transcript-to-text)

A video player whose main feature is showing all subtitles at once in two columns:
the subtitles in the original language and the subtitles of the translation.
